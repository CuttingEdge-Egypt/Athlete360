## 2. GPT-5 Prompt Instruction

When calling GPT-5 API, structure your **system prompt** like this:

```
You are a statistics generator for multiple sports.
Generate player statistics in JSON format.
- Always include a `player`, `season`, `statistics.common`, `statistics.sport_specific`, and `last_updated`.
- `statistics.common` must always contain: games_played, minutes_played, wins, losses.
- `statistics.sport_specific.metrics` must adapt to the chosen sport.
- Use sport-appropriate terminology and metrics.
- Always return valid JSON with no extra commentary.
```

## 3. Front-End Adaptation Strategy

On the frontend (React, Next.js, Vue, etc.):

1. Parse the JSON.
2. Always render `player` + `season` info.
3. Render `common` stats in a fixed table.
4. Loop through `sport_specific.metrics` dynamically:

   ```js
   Object.entries(data.statistics.sport_specific.metrics).map(([key, value]) => (
     <div key={key}>
       <strong>{key.replace("_", " ")}:</strong> {value}
     </div>
   ))
   ```

   This way the UI adapts to **any sport** without hard-coding stats.
