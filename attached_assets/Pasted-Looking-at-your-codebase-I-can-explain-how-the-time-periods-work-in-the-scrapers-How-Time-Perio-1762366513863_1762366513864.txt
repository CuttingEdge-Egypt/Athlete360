How Time Periods Work
The scrapers fetch data based on month and year parameters. Here's the breakdown:

1. Rankings API (scraper.py)
Uses month and year parameters
Month is 0-indexed (0=January, 1=February, ..., 11=December)
Example: month=7&year=2025 fetches data for August 2025
def _get_month_number(self, month_name: str) -> int:
    """Convert month name to number (0-based: January=0, February=1, etc.)"""
    months = {
        'January': 0, 'February': 1, 'March': 2, 'April': 3,
        'May': 4, 'June': 5, 'July': 6, 'August': 7,
        'September': 8, 'October': 9, 'November': 10, 'December': 11
    }
    return months.get(month_name, 6)
2. Competition/Profile API (working_api_scraper.py)
Also uses month and year parameters with the same 0-indexed convention
Fetches athlete profile data and competition history up to that date
The API returns all competitions in the athlete's history, not just from that specific month
3. Multi-Period Fetching (app.py)

Why Multiple Periods?
The API response can vary depending on when you query it:

Rankings change over time
Competition data may be updated or added retroactively
Historical snapshots at different points capture the full athlete journey
