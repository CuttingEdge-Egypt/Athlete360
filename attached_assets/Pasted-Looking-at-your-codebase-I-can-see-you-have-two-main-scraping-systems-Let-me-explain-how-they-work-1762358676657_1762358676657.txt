1. Ranking Scraper (scraper.py)
This scraper fetches athlete rankings from the World Taekwondo API:

How it works:
Step 1: Session Initialization

Uses cloudscraper library to bypass Cloudflare protection
Creates a browser-like session with proper headers to mimic Chrome
Visits the main website first to establish cookies and session
Step 2: Building API Request

URL: https://worldtkd.simplycompete.com/rankingsV2
Parameters:
- rankingTypeId: Which ranking system (World/Olympic)
- subCategory1: Division (Senior/Junior)
- rankingCategoryId: Weight division (M-58kg, W-49kg, etc.)
- countryId: Filter by country (optional)
- month: 0-indexed (0=Jan, 11=Dec)
- year: Year for rankings
- limit: Results per page (100)
- pageNo: Pagination
Step 3: Data Extraction

Makes GET request to API endpoint
Receives JSON response with athlete data
Extracts: rank, name, country, points, userid, wtfLicenseId, gender, profile picture
Handles pagination (fetches multiple pages if needed)
Step 4: Filtering

Applies athlete name filter (partial match)
Removes duplicates
Limits results based on max_results setting
2. Competition Scraper (working_api_scraper.py)
This scraper fetches detailed athlete data including competition history:

How it works:
Step 1: Uses Different API Endpoint

URL: https://worldtkd.simplycompete.com/getPlayerProfileV2
Parameters:
- userId: Athlete's unique ID (from ranking scraper)
- month: Same 0-indexed month

- countryId, rankingTypeId, subCategory1: Same as ranking scraper
Step 2: Session Setup

Same cloudscraper approach for Cloudflare bypass
