Looking at the code, I can identify the main bug and several potential issues:

## Main Bug: Comparison Generation Stuck in Loading

The issue is in the `handleViewResult` function. When a comparison generation completes, it doesn't properly update the queue item status because:

1. The comparison generation completes and calls `updateGeneration` with status 'completed'
2. But when you click to view the result, it navigates away without updating the UI state
3. The queue item remains in the running state visually

**Fix for the comparison bug:**

```tsx
const handleViewResult = (item: GenerationItem) => {
  if (!item.result) return;

  console.log('Queue result clicked:', item);
  
  if (item.serviceType === 'comparison') {
    // Navigate to home with comparison tab and data
    const encodedData = encodeURIComponent(JSON.stringify(item.result));
    const url = "/?tab=comparison&data=" + encodedData;
    console.log('Navigating to comparison:', url);
    
    setLocation(url);
    setTimeout(() => {
      window.history.pushState({}, '', url);
      window.dispatchEvent(new PopStateEvent('popstate'));
      
      // Remove the completed comparison from queue after navigation
      removeGeneration(item.id);
    }, 100);
  } else if (item.serviceType === 'video') {
    // Navigate to video analysis page with data in sessionStorage
    sessionStorage.setItem('videoAnalysisData', JSON.stringify(item.result));
    setLocation('/video-analysis');
    
    // Remove the completed video analysis from queue after navigation
    removeGeneration(item.id);
  } else if (item.serviceType === 'statistics') {
    // Show analysis popup for statistics
    setSelectedResult(item);
    setShowAnalysisPopup(true);
  } else {
    // Show analysis popup for other types
    setSelectedResult(item);
    setShowAnalysisPopup(true);
  }
};
```

## Recommended Comprehensive Fix:

1. **Add proper cleanup for timeouts:**
```tsx
useEffect(() => {
  return () => {
    // Clean up all timeouts when component unmounts
    Object.values(timeoutIds).forEach(timeouts => {
      timeouts.forEach(timeout => clearTimeout(timeout));
    });
  };
}, [timeoutIds]);
```

2. **Improve the comparison completion handling:**
```tsx
// In updateGeneration, ensure comparison items are properly marked complete
if (updates.status === 'completed') {
  // For comparison items, we might want to auto-navigate or just mark complete
  if (item.serviceType === 'comparison' && updates.result) {
    // Optionally auto-navigate or just leave in queue for user to click
  }
}
```

3. **Add proper error handling:**
```tsx
const getServiceLabel = (serviceType: string) => {
  try {
    const serviceLabels: { [key: string]: string } = {
      // ... labels
    };
    return serviceLabels[serviceType] || serviceType;
  } catch (error) {
    console.error('Error getting service label:', error);
    return serviceType;
  }
};
```

The main issue is that comparison generations complete but don't get properly removed from the queue when viewed, causing the visual inconsistency. The fix above should resolve this by properly removing completed items after navigation.
